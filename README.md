# Визуализатор графа зависимостей (Вариант №4)

## 1. Общее описание
CLI-инструмент на языке Python для анализа и визуализации графа зависимостей пакетов JavaScript (npm). На Этапе 2 реализовано получение информации о прямых зависимостях заданного пакета по HTTP-протоколу из репозитория без использования сторонних библиотек.

## 2. Описание всех функций и настроек
* **Параметры командной строки (`argparse`):**
  * `--package` — имя анализируемого пакета (обязательный).
  * `--repo` — URL-адрес репозитория npm или путь к файлу тестового репозитория (обязательный).
  * `--test-mode` — флаг включения режима работы с тестовым репозиторием.
  * `--output` — имя выходного файла с изображением графа (по умолчанию `graph.svg`).
  * `--ascii` — флаг вывода зависимостей в формате ASCII-дерева.
  * `--max-depth` — максимальная глубина анализа зависимостей (по умолчанию `3`).
* **Основные функции (`src/main.py`):**
  * `parse_arguments()` — считывает и разбирает опции командной строки.
  * `validate_arguments(args)` — проверяет корректность всех переданных параметров и выбрасывает исключение `ValueError` при ошибках.
  * `fetch_npm_dependencies(package_name, repo_url)` — обращается к репозиторию по URL через стандартный модуль `urllib.request`, декодирует JSON-ответ и извлекает словарь прямых зависимостей (`dependencies`) последней версии пакета.
  * `print_dependencies(package_name, dependencies)` — выводит список прямых зависимостей пакета на экран.

## 3. Описание команд для сборки проекта и запуска тестов
* **Сборка проекта:** не требуется (интерпретируемый язык Python).
* **Запуск проекта:** выполнить пакетный файл `run.bat` (он автоматически поднимает локальный HTTP-сервер реестра для стабильной демонстрации) или запустить напрямую:
  ```bash
  python src/main.py --package express --repo http://127.0.0.1:8000
  ```
* **Запуск тестов:**
  ```bash
  python -m pytest
  ```

## 4. Примеры использования
При запуске `run.bat` программа обращается по HTTP-адресу репозитория и выводит прямые зависимости пакета `express`:
```text
Прямые зависимости пакета 'express':
- accepts: ~1.3.8
- body-parser: 1.20.3
- cookie: 0.7.1
- debug: 2.6.9
- merge-descriptors: 1.0.3
```
