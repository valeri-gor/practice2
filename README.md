# Визуализатор графа зависимостей (Вариант №4)

## 1. Общее описание
CLI-инструмент на языке Python для анализа и визуализации графа зависимостей пакетов JavaScript (npm). На Этапе 1 реализован минимальный прототип с приёмом параметров командной строки и валидацией ошибок.

## 2. Описание всех функций и настроек
* **Параметры командной строки (`argparse`):**
  * `--package` — имя анализируемого пакета (обязательный).
  * `--repo` — URL-адрес репозитория или путь к файлу тестового репозитория (обязательный).
  * `--test-mode` — флаг включения режима работы с тестовым репозиторием.
  * `--output` — имя выходного файла графа (по умолчанию `graph.svg`).
  * `--ascii` — флаг вывода зависимостей в формате ASCII-дерева.
  * `--max-depth` — максимальная глубина анализа зависимостей (по умолчанию `3`).
* **Основные функции (`src/main.py`):**
  * `parse_arguments()` — считывает флаги командной строки.
  * `validate_arguments(args)` — проверяет корректность всех параметров и выбрасывает исключение `ValueError` при ошибках.
  * `print_config(args)` — выводит настройки в формате `ключ: значение`.

## 3. Описание команд для сборки проекта и запуска тестов
* **Сборка проекта:** не требуется (интерпретируемый язык Python).
* **Запуск проекта:** выполнить файл `run.bat` или команду:
  ```bash
  python src/main.py --package express --repo https://npmjs.org --output graph.svg --ascii --max-depth 3
  ```
* **Запуск тестов:**
  ```bash
  python -m pytest
  ```

## 4. Примеры использования
При запуске `run.bat` программа выводит текущую конфигурацию:
```text
package: express
repo: https://npmjs.org
test_mode: False
output: graph.svg
ascii: True
max_depth: 3
```
